# 剧情线

把线定义放在 `data/<命名空间>/meridian_story/line/<路径>.json`，路径决定线 ID。格式版本是 1。`origin` 可省，通用线从身体和在线时钟就绪后启用。出身线在选定或已选玩家重进时接上。`first`、`chapters` 的键和每个事件的 `id` 都是存档身份，更新内容时沿用原名。事件 ID 缺省取类型名。

每章的 `when` 数组取交集，`on` 数组列出本章可响应的外部事件。每个分支从 `next`、`finish` 和 `stay: true` 选一项。留在原章需要新的外部事件才能再走。开服核对出身、仇家、队伍、实体、信物引用、分支和可达性。重载期间整份新表通过校验才生效，旧对话随成功重载过期。移走线或当前章会暂停该线，重放原 ID 后按身体里的进度续接。

| 条件类型 | params |
|---|---|
| `origin_ready` | 空对象。收到 CHOSEN 或 READY，并读到身体与在线时钟 |
| `online_days` | `days` 非负整数，`from` 为 `start` 或 `chapter`。一日 24,000 在线 tick |
| `heat_at_least` | `value` 风声下限 |
| `realm_at_least` | `realm` 身体协议的境界名，如 `true_qi` |
| `opened_at_least` | `count` 已开通的脉数 |
| `previous_outcome` | `chapter` 与 `is` 指定已成立的章和分支 |

`raid_settled` 写实际 pending 的 `party` 和 `feud`（通用来犯用空串），必须提供 `win/escape/loss`。入章条件成立后订阅下一次匹配的收场，订阅含章、事件和章节修订号。生人把战果与收场存入同一身体记录，胜场带头目倒下的维度和坐标。剧情先记章节、场次和信物领取权，成功后才确认战果。

`hand_in` 的参数写 `item: minecraft:paper`、`claim`、`count` 和 `to`。`talk` 与 `attack` 写 `to`，按钮可另给 `label` 翻译键。三者都走 `accepted` 分支。潜行右键 NPC 后，打开原版聊天即可点击方括号选项。悬停金色交物选项可看物品名称和数量，出示后自留的选项会注明。灰色「改日再谈」可暂缓决定。聊天记录被顶走时，再次潜行右键同一位 NPC 会重说当前有效邀请，原到期时刻照旧。出手由服务端直接判定。点击只对受邀玩家生效，服务端重新核对会话、NPC、维度、距离、期限、章、凭据与数量。替补信和原信共享领取权。

`do` 中的 `letter` 写 `id` 和 `at: leader_fall`，在胜场放带签记的原版纸。名称和 lore 取 `letter.<线命名空间>.<线路径>.<奖励 ID>` 和同键加 `.lore`。落点没加载或物品遗失时，当前交物章的接信人可以补信。`speech` 写 `speaker: recipient` 与翻译 `key`，由实际接话的生人通过 Taunts 同时发出带名字的聊天和头顶气泡。章节可用 `prompt` 写灰色斜体旁白、`greeting` 写 NPC 的开场白，均取翻译键。

身体内 `meridian_story:progress` 保存协议版本、每条线的入章时刻、分支、最后场次与凭据。宿主拒绝修订号时重读后再算；未知版本或损坏记录保留原值。可直接参考[测试数据包](../../fabric/src/gametest/resources/data/meridian_story_test/meridian_story/line/register.json)。

《云溪剑谱》的卷目、刺撩距离与持剑臂费用见[云溪剑谱](Yunxi.md)。陈恪《寻隙剑谱》三式的位移、钉住目标和费用见[寻隙剑谱](Xunxi.md)。

## 重生归来

选择重生后，旧簿上的仇家开始按你的在线日历计日。第一拨约在第 6–10 日，打赢、逃走或落败都会隔 12–16 日再约一拨。开局保护、上一场来犯的静默期、足够的征兆时间和实际现身地点可能让人晚到。风声、开脉和是否练习溯息诀都不影响这条仇家的资格。结案后仇家仍会再来。

| 章节 | 怎样继续 |
|---|---|
| 旧簿点名 | 留意村民传言和纸条，击败本案头目，去他倒下处捡残页。 |
| 印信倒刻 | 潜行与村民交谈，可交残页比印，也可自己保管，等下一拨对副印。找不到村民时，下一名本案头目身上的副印同样能作证。 |
| 添在死后的名字 | 在主世界有人居住的村钟旁和村民核册，留旁证或取署名页；也可从下一拨旧账抄本查证。手头的纸失落，可向收件的村民补领。 |
| 改写落款 | 在下一拨现身前交证，让村民公开更正并为你说句好话；也可打退头目封存假印。两路各得一封带落款的尾信。 |

作者可用 `notice` 为进入章节、重新登录时的叙述指定翻译键。交互的 `place: village_bell` 要求证人靠近主世界村庄中的钟，`before_arrival` 指定本章的一条仇家。交谈事件可要求出示带签记的纸而由玩家自留，交付事件按数量核销。分支可用 `record_as` 留下不同选择的名字。交付或胜利分支的 `letter` 支持 `at: owner`，先在身体登记领取权，再投进背包；满包或下线会等到下次可投递。交物给村民时可用 `vouch` 写一笔原版正面闲话。

## 平常出身与天煞孤星

「平常出身」用面包作图标，来历是街口寻常人家的孩子，天赋和麻烦两栏均为空。村民按原有声望和你往来。「天煞孤星」的图标是燧石。验收场景里，两种出身都能和游商交谈，走到同一个结局。

「天煞孤星」用燧石作图标。走路、疾跑、跃步和挥击时，参与动作的四肢肌肉多两成耐力。开脉要多守四分之一的时间，首条为 18.75 秒，维持期间照常按秒花费真元。

部位总血量降到 35% 或更低时，「咬牙还手 II」让双臂短时发力，攻速提升一成。图标是带赤纹的握拳；背包里悬停可读说明。回血到一半、经过八个在线秒、死亡或清除状态都会收势。自触发起经过九十个在线秒且回过半血，才会再次触发。路上易遭人拦在出身卡的麻烦栏中列出。

### 借宿脚夫与行路遇袭

在主世界用主手点一处营火，就认下新的宿地。离世界出生点、床和宿地各超过 64 格后，地面步行、潜行和疾跑都算脚程。拆掉营火便解除这处庇护。服务器每秒核对位置和徒步统计；每片 16×16 的路段至多计四秒，折返最近走过的 512 个路段不再累计。首两个在线日为宽限。随后每满六分钟合格脚程抽一次签，中签率四成。完整来犯优先，场地不合适时，下段路沿用同一签。两类场次收场后都要再过两个在线日才重新计路。

| 章节 | 怎样继续 |
|---|---|
| 独行 | 路上打退散兵，收下驿记。逃脱或落败后，还能在下次遭遇再试。 |
| 留宿 | 认下营火，潜行找火边的脚夫说话。聊天栏可用驿记换护送存根，或领取独行路签。 |
| 守住一夜 | 开通一条经脉，带本人凭据再上路会遇到两名追兵。可战胜或甩开他们，也可找这名脚夫引路，独行者能交签换道。落败后还能再试；丢了凭据可在营火旁找脚夫补领。 |
| 还路签 | 回营向脚夫出示存根或路签。护送者领可食用的面包，独行者领盖印的通行纸。结局后仍可能在路上遇到散兵。 |

脚夫案由所有出身共用的行路签启动，每人可结案一次。身体就绪而尚未选卡的人也可遇到。内部仍用 `meridian_story:lone_star` 识别原章、驿记、路签、存根与回执。孤星天生带煞，另算自己的行路签，脚夫结案后仍会有来敌。两种签共用一个战斗场位。

### 近你者见血

天煞孤星在白天经过村外火边可遇见盲眼算命人。村钟须已登记为村庄集合点。付八枚随身铜钱、转身离开或向他出手，都能遇到前往村口的年轻镖师。愿意同走时，留意会绕过你袭击他的散兵。脱战可遣走他，活着护到村口得旗尾结绳。他真死后，心情低落维持七个本人在线日。暂时离开他所在区块，回来仍是原人。

受雇散兵的命帖可以在他倒下的地方搜得。手持使用，记下破幡庙位置，亲自赴庙出手。打赢邪修，到倒地处取手札，手持翻读。暂缓可以重读再选。遗落的命帖、手札回原处补领。收煞后专属签率从四成变五成，咬牙还手 II 持续十二秒、攻速提高一成半，脚夫会畏退，既有存根仍可履约。镇煞后专属签率变两成，还手维持八秒、攻速提高半成，可照常结伴。同行镖师在场时签率为六成半。

## 路上事件：倒在路边的修士

任何出身的生存玩家在主世界白天到黄昏间徒步进入一片未抽过签的 16×16 路段时，若前方有 7×5 的草地或土路、上方三格可穿行，就按两成抽一次签；原地重进、重登不重抽。首两个在线日与每次轻场收场后的两个在线日不开场；每次本事件收场后另有三个在线日冷却。中签后路边多出一名受伤的修士（有身体的流浪商人），落下可治疗的伤后才在聊天栏播开场，潜行与他交谈可重取选项。他怀里只有一份登记为可由剧情授予的通用卷（物品标签 `meridian_story:roadside_scrolls`：袖手拳外卷、破门斩上卷·木门、行矢弓上卷·百步，按场次固定挑一卷）；交给你、被夺走和死后掉落共用这一份，交出或掉过就不会再出现第二份。

| 选择 | 结果 |
|---|---|
| 替他裹伤喂药 | 只在近身、随身带一瓶普通治疗药水且他确有可治伤势时出现。治疗由健康宿主实际回血后才扣药瓶并还空瓶，没回上血就不扣。好签（三分之二）他把卷递给你；坏签排一拨追兵，到场才喝止，此后他跟着你：追兵收场时他仍在 16 格内算护送成功，走散或身亡各有收尾，护送无谢礼。 |
| 动手夺他怀里的卷 | 对他的第一下主动攻击即锁定夺卷，行囊有空位才夺得下来；他死后卷会落在地上。拿到原卷才揭签：好签且无旁人看见就此了结；坏签或 16 格内有其他玩家、村民看见，三到五个在线日后师门来人在路口亮出朱印，之后照常交战或离场。没拿到卷就走远只播未得手。 |
| 让他留在这儿，继续赶路 | 立即收场。不选而走远也会悄悄收场。 |

好坏签在开场时按固定种子锁定，同一场重点、重进不变。收场时伤者会恢复行动、片刻后离开；若他当时所在区块没加载，等区块再载入时按主人的存档核对，案已收就同样放他走。追兵与门人走生人的轻场签号，与孤星行路共用同一序号。

## 剑冢守墓人

剑客养父过世后，你佩着他的旧剑守墓。出身卡权重为 10。首次选定时，服务器在主世界出生点外 32–128 格的干地选址，内圈满后向外找至 192 格。所有守墓人共用一座祖冢，选择出身时各自领养父的旧剑、《云溪旧札》、路引和《云溪剑谱》上下两卷。背包满时保留领取权。右击路引在聊天栏查看主碑坐标，右击旧札可翻读养父的手记。

离冢五个在线日会心情低落，注意组织空闲恢复速度降为八成。回到主碑水平 24 格、高差 8 格以内，连续守候 20 秒可平复。停留满 30 秒可抽一次访客签，两次至少相隔一个在线日，三成半有访客。潜行与携花来的周前辈说话，可接过野花或请他带走。接待后得到一枚旧剑碎片。在登记碑前潜行，用受损的本人旧剑交互可用碎片修补四分之一耐久。手持路引可用一枚铁锭与一枚碎片重铸。两种操作均在聊天栏悬停看代价，确认后结算。原剑可用铁锭在铁砧上维修。

结构模板为 `meridian_story:sword_grave`，25×8×23，南面入冢。Structure-Placer 蓝图共用同一份 NBT。管理员可在主世界用 `/meridian debug grave reserve <north_west>` 为尚无冢址的世界补定西北地面基点，同样检查支撑、净空和建筑。施工中遇占用会停在原位，移开阻挡后继续。

`GraveInheritance.sweptAtGrave` 查询本人首次祭扫且当前身在登记冢内。两卷按每名守墓人的开局领取记录发放。剧情 JSON 的 `start: grave_visit` 在抽中旧识后开章，`place: grave_visitor` 限本人当次到场的说话者。
